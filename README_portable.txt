MapLeadBot portable - Quick start
1. Copy MapLeadBot.exe and gosom.exe from the Releases page on
   GitHub: github.com/gosom/google-maps-scraper into the same folder.
   The scraper is found automatically.
2. Double-click MapLeadBot.exe and answer the questions.
3. The first scraper run downloads its browser; this needs internet
   and can take several minutes.
4. Everything is created NEXT TO THE EXE: ai_config.json, prompts\,
   output\, gui\, ai_cache.jsonl. No Python is needed on this PC.
5. NEVER copy ai_config.json to another PC: enter the API key on each
   PC in the AI settings window instead.
